# 📊 Sales & Return Analysis Dashboard

## 📌 Overview
This project features an interactive Power BI dashboard designed to analyze retail sales performance and product return trends. By integrating operational sales data with return metrics, this dashboard provides key insights into revenue drivers, product return rates, and customer purchasing patterns to help optimize inventory and boost overall profitability.
